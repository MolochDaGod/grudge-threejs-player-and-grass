# Grudge Studio · Three.js Player + Grass Scene
Forked from a Pen by Tezumie ([codepen.io/Tezumie/pen/ByzoOPy](https://codepen.io/Tezumie/pen/ByzoOPy)) and wired up to load the **Grudge Studio race prefab characters** (Bip001 rig + modular equipment from the Unity game) plus a Unity-style controller (WASD + sprint + jump + roll + block + attack + 1–9 hotkeys).
## Convert race FBX → GLB (one-time)
The 6 race characters are sourced from the Asset-Rig-Editor `Toon_RTS` FBX files. Run the converter once to produce `character/races/<PREFIX>_Characters.glb`:
```sh
npm run convert:races
```
This reuses the already-installed `fbx2gltf` binary from the existing `variant-pipeline` so it does not re-download anything. Override `GRUDGE_RACE_FBX_ROOT` or `FBX2GLTF_REQUIRE_FROM` env vars to retarget either path.
## Run locally
The page uses an importmap + ES module imports + `fetch` for GLBs, so it must be served over HTTP. From this directory:
```sh
npx serve .
```
Then open one of:
* `http://localhost:3000/src/`  — working source (live edits without rebuild)
* `http://localhost:3000/dist/` — packaged build (mirror of `src/`)
## Pick a character
Default is `?char=wk` (Human / Western Kingdoms). Use the dropdown in the top-left, or set `?char=<id>` directly:
* `?char=wk`  — Human (Western Kingdoms)
* `?char=brb` — Barbarian
* `?char=elf` — Elf
* `?char=dwf` — Dwarf
* `?char=orc` — Orc
* `?char=ud`  — Undead
Legacy KayKit characters are kept as a secondary tier with their own animation bundle: `?char=knight`, `?char=mage`, `?char=ranger`, `?char=rogue`, etc.
## Controls
| Input | Action |
| --- | --- |
| WASD / Arrow keys | Move |
| Space | Jump |
| Shift | Sprint |
| Mouse | Look (click canvas to capture pointer lock) |
| MouseWheel | Zoom |
| LMB | Attack (one-shot) |
| RMB (hold) | Block |
| LCtrl | Roll (with directional impulse) |
| Q | Dodge |
| 1 – 9 | Skill slots 1–9 |
Attack / Block / Roll / Dodge / Skill slots no-op silently if no clip is bound, so the controller wires up before you have animation GLBs in place.
## Equipment toggling
For Bip001 race characters the right-side **Equipment** panel auto-populates with every armor / weapon / shield / utility variant baked into the FBX (see `EquipmentManager` slot regex in `src/play/equipment-manager.js`). Click a variant letter to equip it; click again to unequip. Behind the scenes this just toggles `mesh.visible` on the matching `*_Units_*` child meshes.

### Weapon hold pose (post-mixer)

**SSOT:** ObjectStore `js/grudge6-weapon-hold-pose.js` (copy: `src/play/grudge6-weapon-hold-pose.js` → `window.Grudge6WeaponHoldPose`).

After each `mixer.update`, play applies the same residual as Main Panel / Casting:

```text
mixer.update(dt)
→ applyWeaponHoldPose(mixer, gait, kind)  // gait from Idle/Walk/Run clip; kind from equipped slot
```

Loaded as a module in `src/play/index.html`. **Do not invent a parallel grip stack** — keep the play copy in sync with ObjectStore.
## Animation hookup
The `Player` class fills its animation slots in this order (per slot, first hit wins):
1. A clip embedded in the character's own GLB whose name matches the slot.
2. `character/races/anims/<characterId>.<state>.glb` (per-character override, Bip001 races only).
3. `character/races/anims/<state>.glb` (shared Bip001 override).
4. For non-Bip001 rigs only: the configured `FALLBACK_BUNDLE` (KayKit `Rig_Medium_*.glb` for KayKit characters, or `Soldier.glb` for legacy Mixamo/CC paths). Bip001 rigs **never** fall back to KayKit/Mixamo because the skeleton differs.
Drop Bip001-rigged GLBs into `character/races/anims/`:
* `idle.glb`, `walk.glb`, `run.glb`, `jump.glb`, `fall.glb`
* `attack.glb`, `block.glb`, `roll.glb`, `dodge.glb`
* `skill1.glb` … `skill9.glb`
Files named `<id>.<state>.glb` (e.g. `wk.attack.glb`) take priority over the generic ones, so you can give the Orc a heavier swing or the Elf a faster bow draw without touching code.

```
├─ character/                 # CC4 / Mixamo legacy GLBs
│  └─ races/                  # Generated by `npm run convert:races`
│     ├─ WK_Characters.glb    # Human (Western Kingdoms)
│     ├─ BRB_Characters.glb   # Barbarian
│     ├─ ELF_Characters.glb   # Elf
│     ├─ DWF_Characters.glb   # Dwarf
│     ├─ ORC_Characters.glb   # Orc
│     ├─ UD_Characters.glb    # Undead
│     └─ anims/               # (drop in your Bip001 anim GLBs here)
├─ scripts/
│  └─ convert-races.mjs       # FBX → GLB converter using fbx2gltf
├─ src/
│  ├─ index.html              # Page + HUD + boot module
│  ├─ style.css
│  ├─ player-config.js        # Character roster, default, anim sources
│  ├─ equipment-manager.js    # window.GrudgeEquipmentManager (Bip001)
│  ├─ grudge6-weapon-hold-pose.js  # hold residual SSOT (ObjectStore mirror)
│  └─ script.js               # Bundled three.js scene + Player + World
└─ dist/                      # Mirror of src/, deployable
```
